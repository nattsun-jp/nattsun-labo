端末にUSB／Bluetoothで接続し、コントローラのボタンを一度押してください。標準パッドは十字キー／左スティックで移動、下のボタン＝P、右＝K、左＝S、START＝一時停止です。

URLバーなしで遊ぶ

iPhoneのSafariでは、ゲームからURLバーを消す全画面表示は使えません。次の手順でホーム画面から起動してください。

COMMAND GUIDE

月城麗の技

「前」は相手の方向、「後」は相手から離れる方向。左右が入れ替わるとコマンドとガードも反転。方向入力は約1秒以内に続け、最後に攻撃ボタンを押します。

技表には斜めを経由する入力経路を記載しています。必殺技1・2と超必殺技は斜めを省略する簡易入力も可能。対空技は最後の前斜め下（↘・↙）が必須です。最後の方向まで入れてからP・K・Sを押してください。

PC：方向キー / WASDで移動・ジャンプ・しゃがみ、J=P、K=K、L=S。スマホ：方向パッドをなぞり、もう一方の指でP/K/S。同じ左右・斜め方向を2回押すとダッシュ。近距離の斜めジャンプで位置を入れ替えられます。投げは左右＋S（空中も可）。相手方向で前投げ、後ろ方向で位置入れ替え。コントローラは「コントローラ設定」で接続・割り当てを確認できます。P・Kの連続入力で3段まで派生。後ろ斜め下（相手が右なら↙、左なら↘）で下段ガード。

キャラと技はナッツんLABOの設定。キャラはオリジナルのセル画調イラスト。パンチ・キック・ガードなど6つの姿勢を切り替えて表示。技のエフェクトはコードによる描画。チャッピーは茶髪・黒×水色パーカーの女の子。追加の素材購入・有料通信API・TURN中継は使用しません。
