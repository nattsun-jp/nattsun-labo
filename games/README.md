# 月城麗の無料ゲーム体験版

公式サイトの games/ 以下で遊べる、登録不要・無料・全年齢の2作品。
- action/: 月城麗と星屑の放課後。3ステージ、2段ジャンプ、ダッシュ、スイッチと通路、動く足場、風、チェックポイント、9枚の思い出メモ、タイムとS〜C評価、実績、全回収の後日談。各ステージのクリアにしおり3枚が必要。しおりは星座柄の紙型で描画。旧v1のセーブは新しい保存がなければ最初のエリアへ引き継ぐ。記録帳と途中セーブは別キー。
- romance/: 月城麗と、放課後の約束。3回の選択・好感度・3つの結末・会話履歴。

どちらも同じブラウザのlocalStorageに1枠保存。サーバーにプレイデータを送信しません。

## BGM

rei-music.jsにオリジナルの32小節ループ2曲を収録。恋愛ノベルは「放課後の約束」（76 BPM、ピアノ風の音色と分散和音）、アクションは「星屑ステップ」（116 BPM、メロディ・ベース・打楽器）。Web Audioで合成し、外部音源・音楽APIは利用しません。ゲーム開始・ロードのユーザー操作後に再生。BGMのON/OFFと音量はゲームごとに端末内保存。アクション一時停止、非表示タブ、ページ離脱時に演奏を止めます。

## アクション v3 / 戦闘・ランキング
ノーマルとハードは記録帳を分離。バケツ（跳ねて接近）、モップ（突進）、箒（空中追尾）が登場し、ハードでは数・速度・耐久が上がる。J/Kまたは蹴りボタンで蹴る。ジャンプ→ダッシュ→蹴りを各1秒以内に順番どおり入力し、空中かつ必殺技が再使用可能なら「月光旋風脚」。必殺技の再使用待ち時間は8秒。絵は既存PixAI立ち絵の上半身とコード描画の蹴り足、敵もコード描画。

共有ランキングは `ranking.js` のSitesサービスへ接続し、モード×ステージ別に上位20件表示。ニックネームは1〜12文字、クリア後に本人が登録ボタンを押して送信。ブラウザの匿名IDごとに各種目のベスト1件。点数はクリア5000＋メモ750/枚＋敵撃破200/体−ミス400/回−経過8/秒。同点ではタイム順。新規開始時に匿名のプレイ開始情報を記録し、サーバーで時間・項目範囲・1回登録を検証。途中セーブの再開はランキング対象外。ブラウザ実行ゲームのため完全な不正プレイ判定はしません。

## LABO FIGHTERS / CPU・TRAINING・FRIEND

fight/ は3キャラの格闘体験版。99秒、2ラウンド先取、最大3決着ラウンド。全12技、通常3段派生、後ろガード・下段ガード・投げ、緑HP/ピンク遅延ダメージ/水色スキルゲージ。トレーニングは入力履歴・コンボ/ダメージ表示、無限ゲージ切替、立ち/ガード/CPU、8つの練習課題、左右/近距離リセット。

無料優先のためフレンド対戦はWebRTC直接接続のみ。STUNは公開の stun.cloudflare.com:3478、TURNは一切設定しない。ルーム保存・マッチング用の課金サーバーや有料APIは使わない。招待/参加コードを2人で交換する方式で、直接接続できない回線は利用不可。CPUと練習は利用できる。ホスト側が試合を計算して相手へ配信するカジュアル対戦用試験版で、競技用のロールバック・不正対策は未実装。新たな外部サービス登録・支払い情報登録なし。

キャラはCanvasによる独自の可動イラスト。チャッピーは参考画像の茶髪・黒×水色の衣装を基準とした女の子、髪飾りは独自のマーク。ナッツんjpは黒帽子の落花生マスコット、麗は制服。既存のオリジナルBGMを利用。

### 格闘ルーム・募集（体験版）
- `games/fight/rooms.js` は既存ランキング用Sitesの `/api/rooms` に接続。6桁ルーム・ニックネーム・募集文・公開/非掲載・2人の準備完了に対応。
- ホストが60fpsで判定し、HTTPSで状態を5回/秒送信。相手の入力順を連番と確認番号で保持。対戦は遅延のある体験版で、ロールバック非対応。
- 新規の課金サービス・決済情報・TURNなし。全員合計20,000 API呼出/UTC日でハード停止（日本時間9時にリセット）。障害時・上限時はCPU/練習を利用。
- 部屋の操作権はサーバー側のランダムトークンのハッシュで検証。募集APIはトークンや対戦状態を公開しない。二重参加は条件付きUPDATEで防ぐ。
- 待機10分、対戦開始から30分で期限切れ。離脱時は募集終了。名前/募集文は文字数制限し、DOMのtextContentで表示。
- Backend source: existing Sites repository `/workspace/sites/rei-shared-ranking`; tests `node tests/rooms.cjs`。

### Fighter illustration assets
- Original cel-shaded 3x2 sprite atlases: Rei / Nattsun / Chappy. Six poses: idle, punch, kick, crouch, guard, hit. Created using built-in image generation; no paid external image API or stock-asset purchase.
- Stored and versioned in existing Sites source `public/fighters/*-atlas-v1.png`; renderer uses its public `/fighters/` static URLs. Alpha channel is preserved.
- Browser rendering selects atlas cells, positions the planted feet and mirrors opponent-facing poses. Match logic and room communication are unchanged.

### 斜め入力・サウンド
- 下段ガードは相手と逆方向＋下（相手右なら↙、相手左なら↘）。立ちガードは横の後ろ。空中攻撃は下段ガードで防げない。
- 必殺技/超必殺技は斜めを経由する波動/半回転入力が使用可能。斜め省略の従来入力も残す。技/コンボ表に相手右・左それぞれの入力経路を記載。
- 新曲『月光バトル・LABO BEAT』144BPMと `fight/sound.js` のオリジナルWeb Audio効果音（選択、攻撃、命中、ガード、ジャンプ、必殺、超必殺、ラウンド、勝利）。有料素材や外部音声APIなし。
- BGMと効果音を別々にON/OFF・音量調整。ブラウザは最初のクリック/タップで音声を有効化。ネットワーク状態の同じイベントを繰り返し鳴らさない。

### 格闘操作・判定 v2
- 立ちP/Kはスプライトの拳先・足先を基準に矩形判定。麗・ナッツん・チャッピーで位置・幅・高さが異なる。下段と空中は立ちの約62％の射程、高さは個別に変更。トレーニングの「当たり判定を表示」で緑の被攻撃判定・ピンクの攻撃判定を確認可能。
- 空中では本体の押し合いを行わず、斜めジャンプの慣性で背後へ回れる。着地後は向きとガードが反転。
- 投げは左右＋S。相手方向なら位置維持、後ろ方向なら位置入れ替え。地上は16、お互い空中の場合は24ダメージ。ゲージ不要、ガード不可。成立した超必殺コマンドは投げより優先する。
- 投げられた側は着地後30フレームのダウン、起き上がり10フレームの硬直。ダウン中は追撃不可。起き上がり中は移動・ガード・攻撃不可。投げ課題は命中時に達成。
- 左右または同じ斜め方向を16フレーム以内に2回入力すると14フレームの高速移動。空中ダッシュは1ジャンプ1回。キーボード・タッチ・Gamepad・ネット入力ともエンジンの同じ判定を使用。
- `fight/gamepad.js` はGamepad APIの標準配置（十字キー／軸0・1、P=0/K=1/S=2/一時停止=9）と機器別割り当てに対応。ボタン・方向ボタン・軸の変更、デッドゾーン、長押しの攻撃連打抑制、非表示／設定画面中の入力抑止、切断時の解除。設定は端末内localStorageに保存。ブラウザ／OSが認識する機器のみ。実機コントローラは未検証。
- 検証: `node games/fight/tests/combat.test.cjs`, `node games/fight/tests/gamepad.test.cjs`, `node games/fight/tests/render.test.cjs`。

### 歩行・しゃがみ攻撃モーション
- 追加の `public/fighters/{rei,nattsun,chappy}-motion-v1.png` は同じ3人のデザインを参照し、組み込み画像生成で制作した透明スプライト。4コマの歩行、しゃがみP、しゃがみKを収録。外部の有料画像APIや購入素材なし。
- 実際に移動した距離から歩行コマを進め、後退時は逆順。停止・壁・空中・被弾・攻撃時は歩行を停止。ネット対戦もホストの歩行位相を配信。
- 下段の入力・ダメージ・攻撃矩形・ガード条件・射程を保持。しゃがみ攻撃で立ち画像全体を縦0.35倍にする処理を削除し、通常の描画倍率で専用絵を表示。しゃがみの被攻撃矩形は、攻撃中も通常のしゃがみ高さに合わせる。
- 画像生成時のセル配置の僅かなずれは元PNGを変更せず、描画用の切り出し・ピボット設定で補正。素材ロード中は既存のしゃがみ絵を表示。
- 検証: `node games/fight/tests/motion.test.cjs` と既存の combat/gamepad/render テスト。
